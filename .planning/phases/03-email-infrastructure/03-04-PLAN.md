    Step 2 — Go to the sealedapp.io registrar DNS panel (the registrar where sealedapp.io is registered).
      Do NOT add these records inside Cloudflare. Cloudflare's only role in this project is Turnstile.

         (shape: resend._domainkey.resend.com)

         (shape: v=spf1 include:_spf.resend.com ~all)
      c) MX: MX record, host "send.sealedapp.io", value from Resend dashboard (Resend's bounce endpoint)

    completes and Resend has seen all records.
