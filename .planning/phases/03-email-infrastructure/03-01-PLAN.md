<objective>
Create Supabase migration 0034 that provisions the custom 7-day verification token table and
the two SECURITY DEFINER wrappers Phase 3 and Phase 4 depend on.

Purpose: Supabase Auth OTP/magic-link expiry is hard-capped at 86,400s (24h) on hosted projects.
EMAIL-04 requires a 7-day TTL. The only conformant path is a custom token table in app_private
with wrappers that let the Edge Function reach it through PostgREST without exposing the private
schema. A second wrapper (lookup_user_id_by_email) is required so Plan 03 can construct a
timestamp-scoped idempotency key for the unverified-resend 1A path.

Output: One SQL migration file ready for `supabase db push` at the handoff (Plan 04).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Edge Function → PostgREST | app_private schema is not exposed; SECURITY DEFINER wrappers in public are the only access path |
| Token URL → Phase 4 verify-email | The token in the URL is the only authentication factor; it must be unguessable, single-use, and time-bounded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | verification_tokens.token | mitigate | encode(gen_random_bytes(32), 'hex') — 256-bit entropy; computationally infeasible to guess |
| T-03-02 | Repudiation | Token replay after use | mitigate | used_at column set on first consumption (Phase 4); partial index WHERE used_at IS NULL enforces lookup efficiency; Phase 4 must check used_at IS NULL before sealing |
| T-03-03 | Repudiation | Expired token accepted | mitigate | expires_at column; Phase 4 verify-email wrapper checks expires_at > now() before consuming |
| T-03-04 | Information Disclosure | app_private.verification_tokens via PostgREST | mitigate | Schema never exposed; RLS enabled; anon/authenticated revoked; service_role only |
| T-03-05 | Elevation of Privilege | Wrapper search-path injection | mitigate | set search_path = '' on both SECURITY DEFINER functions |
| T-03-06 | Information Disclosure | lookup_user_id_by_email leaking existence | accept | Wrapper only returns uuid or NULL; does not confirm email existence to callers beyond what the Edge Function already knows (it already looked up the state); service_role only |
</threat_model>
