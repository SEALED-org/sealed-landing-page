# 01.5-06 — HowItWorks + ResearchSection

## What was built

Two static-content default-export React components for the two main scroll-revealed content sections. Both are zero-props, zero-state, and consume only global CSS classes from Plan 01.5-02 plus the asset PNGs delivered by Plan 01.5-01. Scroll-reveal animations use `motion/react`'s `whileInView` API.

## Tasks completed

### Task 1 — `src/components/HowItWorks.tsx` (101 lines)

Three-column "How it works" section.

- `<section className="how">` → `.how-inner` container
- `motion.div.how-eyebrow` (rule + "How it works" + rule)
- `motion.h2.how-h` "Three steps. *One letter.*" (`<em>` on second clause)
- `.steps-row` containing three `motion.div.step-card`:
  - `01 Write` — `/assets/step-write.png` + h3 with `<span style={{ opacity: 0.38 }}>01</span>{' '}Write a letter to your future self.`
  - `02 Seal` — `/assets/step-seal.png` + h3 "02 Seal it."
  - `03 Open` — `/assets/step-open.png` + h3 with italic `<em>when the time comes.</em>`
- Per-card scroll-reveal stagger: delay 0 / 0.08 / 0.16s
- All `motion.*` elements share `viewport={{ once: true, amount: 0.12 }}`, `initial={{ opacity: 0, y: 20 }}`, `whileInView={{ opacity: 1, y: 0 }}`, `transition.duration: 0.9, ease: easeOut`
