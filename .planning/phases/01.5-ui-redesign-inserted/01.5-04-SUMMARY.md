# 01.5-04 — WaitlistForm + WaitlistSuccessCard

## What was built

Two new sibling components that together implement the hero-form ↔ success-card swap pattern. Both are designed to be always mounted as siblings in `App.tsx` (Plan 01.5-09); CSS class toggles control which one is visually present. The data layer (try/catch/finally + `joinWaitlistLocal`) stays with `App.tsx` per D-06.

## Tasks completed

### Task 1 — `src/components/WaitlistForm.tsx` (59 lines)

Pill-shaped hero email form with loading state.

**Prop contract:**
```ts
interface WaitlistFormProps {
  onSubmit: (email: string) => Promise<void>;
  isSubmitting: boolean;
  isSubmitted: boolean;
}
```

**Rendered markup:**
- `<form id="waitlist" className="waitlist{isSubmitted ? ' is-submitted' : ''}">` — global `.waitlist` rule from 01.5-02 styles the pill shape; `.is-submitted` toggles `display: none`
- Email input: `type="email"`, `required`, `placeholder="Your email address"`, `autoComplete="email"`
- Submit button: `className="btn-primary"`, `disabled={isSubmitting}`
  - While `isSubmitting`: renders `<Loader2 className="w-4 h-4 animate-spin" />`
  - Otherwise: renders `Join the waitlist` + inline arrow SVG

**Data-layer preservation:**
- Form does NOT call `joinWaitlistLocal` directly — `await onSubmit(email)` delegates to App.tsx
- No `try/catch/finally` in the component
- Event type: `React.FormEvent`

### Task 2 — `src/components/WaitlistSuccessCard.tsx` (41 lines)

Always-mounted white card with checkmark stamp and write-letter CTA.

**Prop contract:**
```ts
interface WaitlistSuccessCardProps {
  onWriteLetter: () => void;
  isVisible: boolean;
}
```

**Rendered markup:**
- `<div className="waitlist-success is-mounted{isVisible ? ' is-visible' : ''}" aria-live="polite">`
- `.wls-card` container
- `.wls-head` with `.wls-mark` (inline `<svg>` polyline checkmark `points="20 6 9 17 4 12"`, `stroke="#fff"`, `strokeWidth="2.8"`, `aria-hidden="true"`) + `.wls-title` `"Added to waitlist."`
- `.wls-divider`
- `<button className="wls-next" onClick={onWriteLetter}>` with copy `"Write your first letter now"` + `<span className="arrow" aria-hidden="true">↓</span>` (U+2193)

**Animation hooks (from 01.5-02 CSS):**
- `.is-mounted` flips `display: block`
- `.is-visible` triggers the 550ms opacity/translateY transition + `wls-stamp` keyframe on `.wls-mark` + the always-on `wls-bob` keyframe on `.arrow`
