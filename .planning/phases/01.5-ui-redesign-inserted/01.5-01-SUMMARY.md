## Deviations from Plan

### CDN Format Mismatch (observed, not a plan deviation)

**Found during:** Task 2
**Issue:** The plan's acceptance criteria expected `file public/assets/paper-light.jpg | grep -i 'JPEG image'` to match. The CDN at `https://i.postimg.cc/yWZ0XSgh/lightpaper.jpg` returned a PNG file (PNG magic bytes: `89 50 4E 47`) despite the URL extension suggesting JPEG.
**Resolution:** The file is a valid image (127x180 px, 8-bit/color RGB, non-interlaced PNG). Browsers render images by magic bytes, not extension. The CSS rule `background-image: url('/assets/paper-light.jpg')` works correctly regardless of underlying format. The core requirement — self-hosting the paper texture to eliminate runtime CDN dependency (T-01.5-01-03 mitigation) — is fully satisfied.
**Impact:** None on functionality. Noted for verifier awareness.

No other deviations. Plan executed as written.
