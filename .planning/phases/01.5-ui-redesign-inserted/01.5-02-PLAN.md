<objective>
Extend `src/index.css` with the complete design-token system, all ten ambient `@keyframes`, mobile :root overrides, and the global CSS rules covering every visual section of the prototype, so that Wave-2 component executors can write JSX with `className=\"counter\"` / `className=\"fl-pad\"` / `className=\"faq-item\"` etc. and get the correct rendering with no other styling needed.

Purpose: The prototype's `Landing.html` keeps its CSS in a single inline `<style>` block (lines 11–1331) that the locked UI-SPEC promotes to the source of truth. Lifting these rules verbatim into `src/index.css` is the only way to reach pixel-faithful parity in a reasonable scope — re-deriving each rule via Tailwind utilities would diverge byte-for-byte from the prototype. The Tailwind v4 `@theme` token additions (`--color-ink-*`, `--text-*`, `--color-live-green-*`, `--color-wax-blue`) generate utility class names (`text-ink-70`, `bg-ink-10`, etc.) but the bulk of the consumption is via raw `var()` in the appended global rules. This plan is the foundation for every Wave-2 component plan; without it Wave 2 cannot start.

Output: A single edited file `src/index.css` grown from ~22 lines to several hundred lines. No source code (`.tsx`) files are touched.
</objective>
