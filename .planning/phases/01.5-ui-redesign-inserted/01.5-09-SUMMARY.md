## Data-layer preservation (D-06 — verbatim)

| Block | Behaviour |
|-------|-----------|
| Initial counter fetch | `getSignupCount().then(setWaitlistCount).catch((error) => { console.error('Counter fetch failed:', error); setWaitlistCount(115); })` |
| Hero form submit | `handleSubscribe(formEmail)` with try/catch/finally → `await joinWaitlistLocal(formEmail)`, on success `setIsSubscribed(true)` + `setWaitlistCount((c) => (c ?? 115) + 1)`, on failure `console.error('Subscription failed:', error)`, finally `setIsSubmitting(false)` |
| FirstLetter email submit | Inline async callback → `await joinWaitlistLocal(newEmail)`, on success `setIsSubscribed(true)` + `setWaitlistCount((c) => (c ?? 115) + 1)`, on failure `console.error('Waitlist join failed:', error)` |
| WaitlistSuccessCard CTA | `onWriteLetter={() => document.getElementById('first-letter')?.scrollIntoView({ behavior: 'smooth' })}` |

The `handleSubscribe` signature changed from `(e: React.FormEvent)` to `(formEmail: string)` because the WaitlistForm now owns the email input and surfaces the value via its `onSubmit` prop. The try/catch/finally body, error messages, and downstream state transitions are byte-identical to Phase 1.
