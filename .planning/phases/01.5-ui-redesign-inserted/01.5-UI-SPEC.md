their config overhead, and the prototype's CSS is already prescriptive enough to
copy verbatim.

## Spacing Scale

The prototype uses **arbitrary pixel values** more than a strict 4-pt scale because
of typography-driven vertical rhythm. The contract: lean on multiples of 4 where
possible, but follow the prototype's exact px values for these specific elements
since they were tuned for the type scale.

| Multiple of 4 | Usage |
|---------------|-------|
| 4px | `--space-1` — micro gap, badge dot |
| 8px | `--space-2` — digit gap in counter |
| 12px | `--space-3` — live-row gap, footer link gap |
| 16px | `--space-4` — nav padding, eyebrow gap |
| 24px | `--space-6` — hero headline bottom margin, section-divider gap |
| 28px | (exception) — `.shell` horizontal padding, fl-pad horizontal padding |
| 32px | `--space-8` — wordmark bottom margin |
| 48px | section-divider vertical padding |
| 56px | hero-stamps + wls bottom margin |
| 64px | how-h bottom margin |
| 96px | section padding-y (How, FAQ, FirstLetter) |
| 132px | hero padding-top |

**Exceptions documented (not arbitrary; lifted from Landing.html):**
- `28px` horizontal shell padding (not 32) — preserves prototype rhythm
- `132px 24px 48px` hero padding — exact prototype values
- `40px` translate on wax-seal animation — keyframe choreography requirement

## Animation Specs

All keyframes lifted from Landing.html. Declare them in `src/index.css` so they
can be triggered by either CSS classes or `motion/react` variants.

| Name | Duration | Easing | Trigger | Used in |
|------|----------|--------|---------|---------|
| `wls-stamp` | 500ms | `cubic-bezier(0.34, 1.46, 0.64, 1)` (delay 150ms) | `.waitlist-success.is-visible .wls-mark` | Success card checkmark stamp |
| `wls-bob` | 1.6s infinite | `ease-in-out` | `.wls-next .arrow` (always) | Down-arrow bobbing on "Write your first letter" |
| `ping` | 1.6s–1.8s infinite | `cubic-bezier(0,0,0.2,1)` | `.live-dot::before`, `.count-dot::before` | Live indicator pulse |
| `countBump` | 600ms | `ease` | `.count-num.bump` | Count-pill +1 flash (green tint at 35% keyframe) |
| `blink` | 1.1s infinite | `steps(1)` | `.fl-typewriter .caret` | Cursor blink in typewriter |
| `digitOut` | 500ms | `cubic-bezier(0.7,0,0.3,1)` | `.digit.flip .d-cur` | Counter digit roll-out (translateY 0 → -100%) |
| `digitIn` | 500ms | `cubic-bezier(0.7,0,0.3,1)` | `.digit.flip .d-next` | Counter digit roll-in (translateY 100% → 0) |
| `stepIn` | 400ms | `ease` | `.fl-step-entering` | FirstLetter step transition in |
| `stepOut` | 300ms | `ease` | `.fl-step-leaving` | FirstLetter step transition out |
| `waxDrop` | 950ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` | `.fl-wax-seal` (success step mount) | Wax seal drops onto envelope flap |

**Scroll-reveal pattern (`.reveal` / `.reveal.in`):**
- Initial state: opacity 0, translateY(20px)
- Active state: opacity 1, translateY(0), transition 900ms ease
- Variants `.d1` (delay 80ms), `.d2` (delay 160ms), `.d3` (delay 240ms)
- Trigger: IntersectionObserver at threshold 0.12 (lift the prototype's `<script>` block exactly, OR replicate with `motion/react`'s `whileInView` + `viewport={{ once: true, amount: 0.12 }}`)

**Library split:**
- **`motion/react` v12:** scroll-reveal sections (hero, How cards, Research, FirstLetter head), AnimatePresence for FirstLetter step transitions if not using CSS classes
- **Raw CSS `@keyframes`:** wls-stamp, wls-bob, ping, countBump, blink, digitOut, digitIn, stepIn, stepOut, waxDrop — declare once in `src/index.css`, trigger by class toggles. These are ambient or pure CSS effects where motion library adds no value.
