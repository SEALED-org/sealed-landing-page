## FirstLetter step transitions

| Option | Description | Selected |
|--------|-------------|----------|
| Pure CSS classes | Add `stepIn` / `stepOut` keyframes to `src/index.css`; component toggles a class name when the step changes. Matches the prototype's exact timing (300ms out + 400ms in). Lightweight — no extra JavaScript animation code. | ✓ |
| `motion/react` AnimatePresence | Wrap each step in a motion component and let the library handle mount/unmount fades. More React-native but requires hand-tuning to match the prototype's timing; risks subtle drift from byte-perfect parity. | |

**User's choice:** Pure CSS classes (recommended)
**Notes:** Driver is byte-perfect parity with `Landing.html`. The prototype already tuned both keyframes; lifting them verbatim is lower-risk than re-deriving timings through `AnimatePresence`. Decision captured as D-01 / D-01a in CONTEXT.md. Note: this decision applies only to FirstLetter step transitions — scroll-reveals still use `motion/react`'s `whileInView` pattern per UI-SPEC's library split.
