# 01.5-08 — FAQ rewrite

## What was built

Full rewrite of `src/components/FAQ.tsx` to swap (a) the previous `AnimatePresence` + `height: 'auto'` accordion for a pure-CSS `.faq-item.open` max-height transition, (b) the Lucide `Plus` / `Minus` icon swap for a single inline `<svg className="faq-icon">` rotated 45° via CSS when open, and (c) the 9-entry placeholder array (`"Answer coming soon."`) for the 8 verbatim Q&A blocks from the prototype's `Landing.html` lines 1915–1931.

## What changed

| Before | After |
|--------|-------|
| `AnimatePresence` + `motion.div initial={{ height: 0 }} animate={{ height: 'auto' }}` | Pure CSS `max-height` transition via `.faq-item.open` class |
| `<Plus />` / `<Minus />` swap | Single inline `<svg className="faq-icon">` with two crossed lines; CSS rotates 45° when open |
| 9 placeholder Q&As (`"Answer coming soon."`) | 8 verbatim Q&As copied from the prototype |
| Plain text answers | HTML answers with `<strong>`, `<br><br>`, curly apostrophes — rendered via `dangerouslySetInnerHTML` (safe, developer-authored content) |
| Heading + sub-deck "Everything you need to know" | Heading only: `Frequently Asked Questions (FAQs)` |

## Implementation

- `const faqs: FaqEntry[]` — 8 entries with `{ q: string; a: string }` shape. Verbatim copy from `Landing.html` (Markdown-safe TypeScript string literals; curly apostrophes preserved as `’` to match source).
- `useState<number | null>` open-index single-open accordion pattern. Click on an already-open item closes it (`setOpenIndex(isOpen ? null : i)`).
- Per-item JSX:
  - `.faq-item` (+ `.open` when active) wraps everything
  - `.faq-q` button with `aria-expanded={isOpen}` for screen readers
  - `.num` `<span>` showing `String(i + 1).padStart(2, '0')` ("01"…"08") with CSS variable `--faq-i: i` for stagger animation (declared in global CSS by 01.5-02)
  - `.label` `<span>` for the question text
  - `.faq-icon` inline `<svg>` with two `<line>` elements (vertical + horizontal) — global CSS rotates this 45° to an `×` when `.faq-item.open`
  - `.faq-a` wrapper + `.faq-a-inner` consuming `dangerouslySetInnerHTML={{ __html: f.a }}`
