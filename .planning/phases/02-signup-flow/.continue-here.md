The dashboard for `sealed-landing-page` widget is currently set to Invisible — leave it.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Lazy Turnstile execute on invisible widget | Calling `await ref.execute()` then reading `getResponse()` returns empty because Cloudflare's challenge completion happens asynchronously after the script finishes initializing. Wasted ~30 min debugging "empty token" symptoms. | blocking | Use `onSuccess` callback to capture token into React state; submit reads from state. Pattern is in `src/components/WaitlistForm.tsx` and `src/components/FirstLetter.tsx` as of commit `effe886`. |
| Confusing Turnstile site key vs secret key | The Cloudflare dashboard's widget list TRUNCATES the site key with `...`; the full key is in the widget's Edit page under "Widget Keys". The longer key (`0x4AAAAAADYc8b0oNE4fv3T-VcSLpVAwxeI`) is the SECRET key (server-only); the shorter one (`0x4AAAAAADYc8aBX8NQDwGv4`) is the SITE key (client). Pasting them in the wrong env wastes hours. | blocking | Always copy from the widget's Edit Widget page → Widget Keys section, never from the truncated table view. Site key goes in `.env.local` `VITE_TURNSTILE_SITE_KEY=`; secret key goes ONLY in `supabase secrets set TURNSTILE_SECRET_KEY=...` (never in any repo file). |
| Cross-repo handoff prompt redundancy on platform-injected env | The Phase 2 HANDOFF-PROMPT.md instructed the SEALED-org agent to "confirm SUPABASE_SERVICE_ROLE_KEY is set" — but Supabase auto-injects this into every Edge Function runtime. The check creates confusion (`supabase secrets list` won't show platform-injected vars). | advisory | Future cross-repo handoffs: assume Supabase platform-injected vars (SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY, SUPABASE_DB_URL) are always available to Edge Functions. Don't ask the sibling agent to verify them. |
| AdBlock Plus / browser extensions blocking Cloudflare Turnstile | Tested with AdBlock Plus extension active; intermittently blocked the Cloudflare challenge script, causing onSuccess to never fire. | advisory | Verify in an incognito window before declaring Turnstile broken. Also note for end users: AdBlock Plus is a known blocker; consider including a banner if AdBlock is detected (defer to Phase 5 polish). |
