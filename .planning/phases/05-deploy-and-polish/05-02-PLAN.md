<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → x.com (new tab) | `window.open` to the X compose intent in a new browsing context |
| browser → clipboard | `navigator.clipboard.writeText` writes to the OS clipboard |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-RT2 | Tampering | `window.open(x.com intent)` | mitigate | Pass `'noopener,noreferrer'` to `window.open` so the opened tab cannot reach `window.opener` (reverse-tabnabbing). |
| T-05-CINJ | Information Disclosure / Injection | share text + copied URL | accept | Share text and the copied URL are static, hardcoded constants (`@sealedapp_io`, `https://sealedapp.io`) — NOT user-controlled. No injection surface; values are `encodeURIComponent`-encoded for the intent URL regardless. |
| T-05-CLIPF | Integrity (UX) | clipboard write | mitigate | `try/catch` around `writeText`; the "Copied" confirmation is shown ONLY after the promise resolves — never falsely claim success (honors D-08 spirit). |
| T-05-SC | Tampering | npm/pip/cargo installs | n/a | No package installs. SOCIAL-02/03 use Web Platform APIs + already-installed `lucide-react` (RESEARCH §Standard Stack: "installs no new runtime packages"). dist/ leak gate lives in Plan 04. |
</threat_model>
